# OCR 벤치마크

**현재 측정값 없음.** 실제 기기에서 OCR을 한 번도 실행하지 못했다.

| 항목 | 상태 |
| --- | --- |
| iOS Vision 모듈 코드 | 작성, `swiftc -parse` 구문 검사만 통과 |
| iOS 컴파일 | 미실행 (이 Mac의 Xcode 라이선스 미동의) |
| 지원 언어 런타임 확인 | 코드 작성, 미실행. `supportedRecognitionLanguages()`는 Apple 문서 본문을 가져오지 못해 빌드 때 확인 필요 |
| 한국어 라벨 30개 세트 | 미구성 |
| Android ML Kit | 미구현 |
| 날짜 파서(순수 TS) | 단위 테스트 통과. 실제 OCR 출력이 아니라 합성 문자열 기준 |

## 측정 계획

1. 합성 라벨 30개 이상을 `tests/fixtures`에 구성한다: 명확한 글씨, 작은 글씨, 반사, 기울기, 저조도, 여러 날짜.
2. iPhone에서 날짜 추출 precision/recall과 처리 시간을 측정한다. 저장 정확도는 사용자 확인을 거친 결과로 따로 본다.
3. 실제 포장 사진은 촬영자 동의가 있을 때만 쓰고 저장소에 넣지 않는다.
