# UX 흐름

기준 이미지: `docs/design/ux-board.webp`

## 탭 (4개)

홈 / 냉장고 / 레시피 / 더보기(설정). 냉장고 화면은 보드대로 탭바를 숨기고 하단에 `식재료 추가` 버튼을 둔다. 탭 구조는 프롬프트 권장과 같다.

## 라벨 등록

1. `식재료 추가` → `포장 라벨로 등록`
2. 촬영 또는 앨범 선택 (실패·거부 시 직접 입력 가능)
3. 기기 안에서 OCR
4. 날짜 후보와 원문 확인, 날짜·종류 수정, 2자리 연도 확인. 종류가 `확인 필요`면 다음으로 넘어갈 수 없다
5. 입력 화면: 상품명, 보관 위치, 수량, 라벨 사진·원문 보관 여부(기본 끔)
6. 저장

## 엄마표 반찬

`엄마표 반찬 등록` → 음식 이름, 받은 날짜(필수, 오늘이 기본값이며 수정 가능), 보관 방법, 내 관리 알림(기본 미설정), 메모.

## 레시피

- 직접 등록: 재료(이름·양·단위), 단계. 숫자가 아닌 양은 `약간`처럼 그대로 저장한다.
- 링크 저장: URL, 내 제목, 태그, 메모.
- 상세: 인원수 조절, 단계별 메모, 정착 토글(북마크 또는 기록 영역), 오늘 만들었어요 → 쓴 재료 줄이기, 변경 이력.
- 예시 레시피는 수정 대신 복제한다.

## 냉장고 파먹기

홈 CTA → 일러스트, 대표 추천과 근거 → 조건(정착, 시간, 제외 재료) → 지금 가능 / 재료 추가 필요 목록.

## 데이터 관리

JSON 내보내기(사진 선택), 복원(검증 후 확인), 소진·폐기 기록 복구, OCR 원문 삭제, 예시 삭제, 전체 삭제.
