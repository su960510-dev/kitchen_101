# 디자인 QA

2026-11-03, Expo 웹 미리보기 390×844 뷰포트에서 보드와 비교했다. **iOS 실제 렌더링이 아니므로 기기에서 다시 확인해야 한다.**

| 보드 화면 | 웹 미리보기 | 차이 |
| --- | --- | --- |
| 홈 | 일치 | 예시 안내 바, 파먹기 CTA, 빠른 등록 추가. 문구 변경 |
| 냉장고 | 일치 | 날짜 종류, 예시 뱃지, 뱃지 아이콘 추가 |
| 식재료 추가 | 일치 | 이름 입력칸, 촬영·앨범 버튼, 예시 뱃지 추가 |
| 레시피 상세 | 일치 | 인원수 조절, 단계 메모 입력 추가 |
| 나만의 레시피 | 일치 | 예시 뱃지 추가. 격자 6개 |
| 냉장고 파먹기 | 일치 | 추천 근거, 조건 추가. 문구 변경 |
| 앱 아이콘 | 벡터 재작성 | 도형 동일 |

의도한 차이의 근거는 `DECISIONS.md`.
