# 레시피 저작권 정책

- 외부 레시피는 URL, 사용자가 직접 쓴 제목, 태그, 메모만 저장한다. 저장 시 네트워크 요청을 보내지 않는다.
- 페이지 본문, 사진, 영상, 자막, 썸네일, 댓글을 가져오지 않는다. oEmbed도 쓰지 않는다.
- 링크 열기는 사용자가 누를 때만 일어나고, 대상 사이트를 먼저 알린다. 실패하면 링크 복사를 쓸 수 있다.
- `http`, `https`만 저장한다.
- 레시피 공유·공개 기능은 없다.
- 예시 레시피 문구는 이 프로젝트에서 직접 작성했다. 예시 사진은 사용자가 제공한 UX 보드에서 가져왔으며 권리 확인이 출시 전 과제다(`DECISIONS.md` D-15).
