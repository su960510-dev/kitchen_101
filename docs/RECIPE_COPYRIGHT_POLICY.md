# 레시피 저작권 정책

- 외부 레시피는 URL, 사용자가 직접 쓴 제목, 태그, 메모만 저장한다. 저장 시 네트워크 요청을 보내지 않는다.
- 페이지 본문, 사진, 영상, 자막, 썸네일, 댓글을 가져오지 않는다. oEmbed도 쓰지 않는다.
- 링크 열기는 사용자가 누를 때만 일어나고, 대상 사이트를 먼저 알린다. 실패하면 링크 복사를 쓸 수 있다.
- `http`, `https`만 저장한다.
- 레시피 공유·공개 기능은 없다.
- 예시 레시피 문구는 이 프로젝트에서 직접 작성했다. 예시 사진은 사용자가 제공한 UX 보드에서 가져왔으며 권리 확인이 출시 전 과제다(`DECISIONS.md` D-15).
- 사용자가 직접 복사해 붙여넣은 레시피 글은 기기 안에서 재료·순서 초안으로 나누기만 하고 원문은 저장하지 않는다. 앱이 링크 속 페이지나 영상을 열거나 가져오지 않는다. 정리 결과는 사용자의 개인 기록이며 공유 기능은 없다.
- (2026-11-10, D-24) 사용자가 `링크에서 레시피 불러오기`를 누르면 그 링크 하나를 기기에서 열어 구조 데이터·본문·YouTube 설명란과 메인 댓글에서 재료와 순서만 초안으로 만든다. 원문·사진·영상은 저장하지 않는다. 이 기능은 프롬프트의 원래 정책을 사용자 결정으로 바꾼 것이며, 출시 전 약관 검토가 필요하다.
- (D-25) 인스타그램은 링크 미리보기용 공개 캡션만 읽는다. 로그인이 필요한 화면, 댓글, 영상은 다루지 않는다.
