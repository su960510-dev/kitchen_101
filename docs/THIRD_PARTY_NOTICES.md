# 제3자 고지

앱에 포함되는 오픈소스는 React, React Native, Expo 및 Expo 모듈, Expo Router, react-native-screens, react-native-safe-area-context, react-native-svg, react-native-web(웹 미리보기)이며 모두 MIT 라이선스다. 버전은 `MODEL_AND_LIBRARY_LICENSES.md` 참고.

MIT 라이선스 전문 고지를 앱 안 화면에 자동 생성하는 작업은 출시 전 과제다. 현재 앱 안내 화면에는 요약과 이 문서 안내만 있다.

## 이미지 자산

`assets/images`의 사진과 일러스트는 사용자가 제공한 UX 보드(`docs/design/ux-board.webp`)에서 `scripts/extract-board-assets.mjs`로 추출했다. 원본 출처와 상업적 사용 권리는 미확인이다.
