# 개인정보

- 로그인, 분석 도구, 광고 SDK, crash reporting SDK가 없다.
- 식품 재고, 가구 인원, 레시피, 사진, OCR 원문은 앱 내부(SQLite, 앱 전용 폴더)에만 저장한다. DB 파일은 암호화하지 않고 OS 샌드박스에 의존한다.
- 네트워크를 쓰는 기능: 사용자가 누른 외부 레시피 링크 열기, 안내 화면의 공식 출처 링크 열기, `링크에서 레시피 불러오기`(그 링크 하나와, YouTube 링크면 Google의 YouTube Data API). 이때 상대 서버는 기기의 IP 주소와 요청한 링크를 알게 된다. 식재료·레시피·사진 같은 앱 데이터는 보내지 않는다.
- 권한: 카메라(라벨·음식 촬영, 사용할 때만 요청), 알림(켤 때만 요청). 사진은 OS 선택기를 쓴다. 위치, 마이크, 연락처는 요청하지 않으며 Android 매니페스트에서 제거한다.
- 라벨 사진과 OCR 원문은 기본 보관하지 않는다. 사용자가 켤 때만 보관한다.
- 로그에 사용자 내용을 남기지 않는다(`logError`).
- 내보내기 전에 민감 정보 경고를 표시하고, 저장 위치는 사용자가 고른다.
- 전체 삭제: 더보기 → 데이터 관리. 앱 삭제 시 정리 동작은 실제 기기에서 아직 확인하지 않았다.
